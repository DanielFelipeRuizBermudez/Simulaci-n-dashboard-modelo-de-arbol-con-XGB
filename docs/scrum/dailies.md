# Bitácora de Daily Scrums

Registra: Michelle. Máximo 15 minutos. Cada integrante responde: ¿qué hice?, ¿qué haré?, ¿qué me bloquea?
Se registran solo las Dailies que realmente se hicieron (fecha, hora y medio reales).
